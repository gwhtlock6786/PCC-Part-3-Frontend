Step 17

Copy an Object with Object.assign

Uses Object.assign() to create a new object without changing the original object.

Results will appear here...
Object.assign()

We can copy an object like this:

const newObject = Object.assign({}, oldObject);

We can also copy an object and change a property:

const newObject = Object.assign( {}, oldObject, { name: "Gershon" } );

The important part is that the original object is not changed.
