Step 16

Remove an Item from an Array

Removes an item from an array without changing the original array.

Results will appear here...
Instead of changing the original array:

state.splice(...)

We can use:

state.filter(...)

filter() creates a new array containing only the items that pass the condition.

This makes it useful for maintaining immutable Redux state.
