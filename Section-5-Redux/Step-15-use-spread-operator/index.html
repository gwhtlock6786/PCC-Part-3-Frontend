Step 15

Use the Spread Operator on Arrays

The spread operator allows us to create a new array containing the values from an existing array.

Results will appear here...
Basic Spread Syntax:

const newArray = [...oldArray];

To add something to the new array:

const newArray = [...oldArray, newItem];

This creates a NEW array instead of modifying the original array.
