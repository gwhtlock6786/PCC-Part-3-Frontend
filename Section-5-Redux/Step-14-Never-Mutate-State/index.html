Step 14

Never Mutate State

Redux state should never be changed directly. Instead, the reducer should create and return a new state.

Redux state will appear here...
Do NOT mutate the existing state:

state.push(action.todo)

Instead, create a new array:

return [...state, action.todo]

The original array stays unchanged, and Redux receives a completely new array as the new state.
