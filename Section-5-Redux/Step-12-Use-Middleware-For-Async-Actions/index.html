Step 12

Use Middleware to Handle Asynchronous Actions

Redux normally expects dispatch() to receive an action object. Redux Thunk middleware allows us to dispatch a function that can perform asynchronous work before dispatching a normal Redux action.

Click "Request Data" to start the asynchronous Redux test.
What this exercise demonstrates:

Without middleware:
dispatch(action)

With Redux Thunk middleware:
dispatch(function)

The function can perform asynchronous work and then dispatch a normal Redux action when the data is ready.
